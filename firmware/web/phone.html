One-time setup to save many at once

To save one photo, open it, press and hold, and tap Save to Photos. That needs no setup.

To save a whole selection in one go, add a free Shortcut once:

  1. Open the Shortcuts app and tap +. Name it exactly Save from Digicam.
  2. Add Split Text. Set it to split Shortcut Input by New Lines.
  3. Add Repeat with Each (it uses the Split Text).
  4. Inside the repeat, add Get Contents of URL with Repeat Item.
  5. Inside the repeat, add Save to Photo Album (Contents of URL). Pick an album such as Digicam.
  6. Done. The first time, allow it to find devices on your local network.

Or, if someone sent you the Shortcut as a link, open the link and tap Add Shortcut.
